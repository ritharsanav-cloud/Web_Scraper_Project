# Web Scraper using Python and BeautifulSoup

## Objective

The objective of this project is to automatically collect quotes and author names from the website **quotes.toscrape.com** using Python.

## Features

* Scrapes quotes from 10 web pages
* Collects 100 quotes automatically
* Extracts author names
* Saves data into `quotes.csv`
* Displays the total number of quotes collected
* Allows users to search quotes by author name

## Technologies Used

* Python
* Requests
* BeautifulSoup
* CSV Module

## How to Run

1. Install Python.
2. Install the required libraries:

```
pip install requests
pip install beautifulsoup4
```

3. Run the project:

```
python scraper.py
```

## Output
